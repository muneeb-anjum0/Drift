# Phase III-J proposal — targeted semantic-boundary repair (not authorization to train)

Status: **PROPOSAL ONLY**. Phase III-I.5's preregistered stress test found recurring cross-domain semantic-boundary errors and concluded **TARGETED RETRAINING SCOPE REVISED**. Its raw result was 161/215 correct (74.88%; macro F1 75.89%) with 216/216 structurally valid. The current Q4_K_M model, P1, PP1, retrieval, and production defaults remain frozen. No training, GPU use, cloud rental, model release, or promotion is authorized by this document.

## Objective and hypothesis

The co-primary targets are (1) removed versus modified when an explicit baseline option, delivery channel, data item, or permitted scope is eliminated while another baseline behavior remains, and (2) contradiction versus modified when a request violates an explicit baseline invariant. III-I.5 observed 16/43 removed cases labeled modified across 12 domains and 18/28 contradiction misses across 11 domains, including 15 labeled modified. Addition versus modification is a bounded secondary target (11/38 added cases labeled modified). III-I.5's paraphrase, distractor, and clause-order flips require robustness gates, not direct copying of its protected cases into training. The Phase III-I seven same-domain unchanged-to-drift errors remain **label-sensitive** because those messages request unrelated new capabilities; they must not become training targets until a separate human adjudication resolves the P1 interpretation. All Phase III-D, III-E, frozen III-I, and III-I.5 examples and near-paraphrases are closed and must never enter train, validation, prompt examples, or development tuning. The [III-I.5 report](phase_iii_i_5_final_report.md) is the aggregate evidence source.

## Model experiment

Use the same Qwen2.5-7B base for one defensible first controlled comparison so the primary variable is repaired supervised data, not a simultaneous base-model change. Reconstruct the exact base and adapter lineage before training. Compare the frozen current Q4_K_M model against a new LoRA/QLoRA adapter trained from the approved grouped corpus. Change one factor at a time; do not run an uncontrolled hyperparameter sweep. The historical r16/alpha32/dropout 0.05 setup is a reproducibility reference, not an unexamined default; predeclare any hyperparameter change and a bounded development-only comparison. Preserve rejected experiments. Record tokenizer, base revision, adapter configuration, seed, library versions, dataset hashes, checkpoint hashes, quantization path, and generation settings. Do not reuse any closed final cases as few-shot examples or training data.

The candidate must improve independently reviewed removed recall and removed-versus-modified confusion **and** contradiction recall and contradiction-versus-modified confusion, with bounded addition-to-modified improvement and without material regression on true modifications, ambiguous, unchanged, JSON validity, or latency/resource limits. Include preregistered paraphrase, distractor, order, and repeat-stability checks. Report raw numerators and per-class metrics; do not select a winner from accuracy alone. Run a fresh final exactly once. Include PP1 ablation and an end-to-end retrieval-separated check so classifier gains are not confused with requirement-delivery changes. No production promotion follows merely from a successful training run.
